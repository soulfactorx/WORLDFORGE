# WORLDFORGE 통합 시스템 설계서 v3.0

> 원 설계서 v2.0(사용자 작성)과 설계 검토(`design-review-v2.md`)를 바탕으로, **v0.19.1까지 실제로 만든 것**을 반영해 다시 정리한 문서다.
> v3의 목표는 하나다 — **여러 장르의 RPG를 같은 엔진으로 돌린다.** 판타지·다크 판타지·현대 이능력·SF·사이버펑크·포스트 아포칼립스·무협·공포·로맨스·미스터리·학원.
> 이를 위해 세계·인물·관계·적·스토리·퀘스트를 **장르에 묶이지 않는 공통 모델 + 장르별 프로필**로 나눈다.

## 1. 설계 원칙 (v2에서 유지 · 변경)

**유지**
1. 자체 세계관 구조가 모든 기능의 기반. CHARX는 변환 대상일 뿐 실행 규격이 아니다.
2. 플레이어는 1인칭, 세계를 모른 채 시작한다. (시작 방식이 "원작 지식"을 줄 수는 있다 — 구현됨)
3. **AI는 서술·연기·해석, 엔진은 결과 결정, 데이터는 진실.** AI는 구조화된 요청만 내고 엔진이 검증한다.
4. NPC는 자기 지식만 안다(프롬프트 단계에서 차단 — 구현됨).
5. 세이브는 이벤트 로그, 패키지는 문서. 패키지가 바뀌어도 세이브는 그대로.

**변경·추가**
6. **싱글플레이 · 서버 없음.** 계정·DB·관리자 도구는 범위 밖. 모든 데이터는 사용자 기기에. AI는 사용자 키(BYOK) 또는 로컬 모델.
7. **장르 중립 코어.** 엔진의 어떤 모듈도 "판타지"를 가정하지 않는다. 마법·기술·초능력은 모두 **"능력 원천(power source)"** 데이터다.
8. **규칙은 데이터.** 직업·능력·적·아이템·상태이상은 패키지 데이터로 정의하고, 엔진은 정해진 **효과 DSL**만 실행한다. (코드 실행 없음)
9. **스토리는 AI가 쓰지만 뼈대는 데이터.** 제작자(또는 AI 생성 보조)가 정한 줄기·사건·조건을 엔진이 판정하고, AI는 그 사이를 자연스럽게 잇는다.
10. **타인의 작품은 개인용.** 카드 등으로 만든 세계는 공유 불가 표시, 기기 간 이동만 허용(구현됨).

## 2. 장르 시스템

### 2.1 장르 프로필 (Genre Profile)

세계(WPK)는 하나의 **장르 프로필**을 고른다(기본 + 덧붙이기 가능). 프로필은 엔진 동작을 바꾸지 않고 **기본값과 사용 가능한 부품**만 정한다.

```jsonc
"genre": {
  "base": "dark_fantasy",              // 아래 표의 ID
  "tags": ["court_intrigue", "isekai"], // 보조 성격 (분위기·퀘스트 템플릿 가중치)
  "tech": "medieval",                  // stone | medieval | industrial | modern | near_future | far_future
  "powerSources": ["arcane", "divine"],// 이 세계에 있는 능력 원천
  "currency": { "name": "크라운", "symbol": "₵" },
  "tone": { "violence": 2, "horror": 2, "romance": 1, "humor": 0 }, // 0~3, 등급과 별개인 연출 강도
  "rulesProfile": "core_d20"           // 2.2의 규칙 프로필
}
```

| 장르 ID | 기본 능력 원천 | 특수 규칙 모듈(2.3) | 기본 적 세트 | 대표 퀘스트 유형 |
|---|---|---|---|---|
| `high_fantasy` | arcane, divine, primal | — | 야수·고블린·언데드·용 | 토벌·탐험·호위 |
| `dark_fantasy` | arcane, divine, pact | 타락(Corruption) | 언데드·이형·광신도 | 생존·토벌·배신 |
| `modern_supernatural` | psychic, pact, tech | 은폐(Masquerade) | 괴이·조직원·변이체 | 조사·잠입·보호 |
| `sci_fi` | tech, psionic | 장비 출력·연료 | 드론·외계 생물·용병 | 탐사·구조·전달 |
| `cyberpunk` | tech, cyber | 열·과부하(Heat), 해킹 | 경비·갱단·보안 AI | 잠입·탈취·거래 |
| `post_apocalypse` | tech, mutant | 보급(Supply), 방사능 | 약탈자·변이 짐승 | 생존·수집·방어 |
| `wuxia` | qi | 내공(Qi), 문파 평판 | 무인·산적·요괴 | 결투·복수·호위 |
| `horror` | pact, psychic | 공포(Stress)·정신력 | 괴물·망령·숭배자 | 생존·조사·탈출 |
| `romance` | (선택) | 관계 사건 강화 | (전투 적음) | 관계·사교·선택 |
| `mystery` | (선택) | 단서·추리 | (전투 적음) | 조사·심문·추리 |
| `academy` | arcane/psychic | 시간표·평판 | 라이벌·시험 괴물 | 시험·동아리·사건 |

> 한 세계에 여러 장르를 섞는 것은 `tags`로 한다 (예: 판타지 + 로맨스 + 궁중 암투).

### 2.2 규칙 프로필 — d20 코어는 하나

모든 장르는 **SRD 5.2.1 기반 d20 코어**를 공유한다: 능력치 6종, 숙련 보너스, 판정·내성·공격, HP·AC, 행동 경제, 휴식, 레벨.
장르는 다음만 바꾼다.

| 바꿀 수 있는 것 | 예 |
|---|---|
| 직업의 **외형**(이름·설명·카드 이름) | 위저드 → "해커"(사이버펑크), "술사"(무협) |
| **기술 이름**의 표시 | 비전학 → "기술학", 종교 → "강호 견문" |
| **자원 이름** | 주문 슬롯 → "배터리", "내공" |
| **무기·방어구 표** | 검·활 → 권총·소총·사이버 손톱 |
| **특수 규칙 모듈** 켜기 | 2.3 |
| 성장 속도·최대 레벨 | 단편 공포는 레벨 1~3, 장편 판타지는 1~10 |

→ 엔진 코드는 하나, 장르는 **"리스킨 + 모듈"**. 새 장르를 만들 때 코드를 고치지 않는다.

### 2.3 특수 규칙 모듈 (켜고 끄는 부품)

모두 "**미터**(0~N 수치) + **임계값 효과** + **회복 방법**"이라는 같은 틀로 만든다.

| 모듈 | 미터 | 임계 효과 예 | 회복 |
|---|---|---|---|
| 공포/스트레스 | Stress 0~6 | 3: 불리점 1회, 6: 공황(행동 상실·도주) | 긴 휴식, 안전한 장소, 동료 대화 |
| 타락 | Corruption 0~10 | 특정 대사·능력 해금, 10: 결말 분기 | 의식·퀘스트 |
| 열/과부하 | Heat 0~5 | 사이버웨어 고장, 경보 | 냉각 행동 |
| 내공 | Qi(자원) | 경공·점혈 카드 비용 | 운기조식(짧은 휴식) |
| 보급 | Supply | 0이면 긴 휴식 불가 | 수집·거래 |
| 은폐 | Exposure 0~5 | 5: 조직의 추적 사건 | 증거 인멸 |
| 단서·추리 | 단서 수 | 추리 판정 DC 감소 | 조사 |
| 평판 | 세력별 -100~100 | 상점 가격·적대·의뢰 | 의뢰·선물 |

엔진은 미터 변화를 **Director 요청 → 검증 → 이벤트**로만 바꾼다(HP와 같은 대우).

## 3. 세계 모델 (WPK 2.0)

### 3.1 엔티티

| 엔티티 | 지금 | v3 추가 |
|---|---|---|
| **Location** | 장소 그래프 | `parent`(대륙>국가>지역>정착지>장소), `kind`(도시·던전·건물…), `danger`, `factionControl`, `tags`(이미지·분위기) |
| **Character** | 성격·말투·배경·관계·동료 | `species`, `role`(주요/일반/적대), `faction`, `goals[]`, `schedule[]`, `statblock`(전투용), `inventory`, `romanceable` |
| **Faction** | — | 이름·목표·자원·영역·관계(세력↔세력)·**행동 시계**(5장) |
| **Species** | — | 이름·특성(SRD 종족 특성 + 외형), 장르별 |
| **Item** | — | 종류(무기·방어구·소모품·열쇠·문서)·가격·카드 부여·효과 DSL |
| **Enemy(Statblock)** | 코드에 2종 | 데이터 정의(4장) |
| **Fact/Claim/Belief** | 구현됨 | `source`(문서·장소·인물), `document` 엔티티(책·편지) |
| **Event** | 연표(카드 세계) | 연표 사건 = 날짜·조건으로 **발동하는** 사건(5.4) |
| **Asset** | 이미지(카드·내장·내 이미지) | 음악·효과음(선택), 장면 태그 |

### 3.2 ID·참조 규칙 (유지)
`종류/슬러그` (예: `npc/hedwig`, `loc/garden`, `fac/hammer`, `item/old-key`, `enemy/wolf`). 패키지 간 참조는 `패키지ID:종류/슬러그`.

### 3.3 스키마 버전
- 지금 `schemaVersion: "0"`에 확장을 계속 덧붙이는 중 → **v1을 이 문서 기준으로 정리**한다. v1 완성 전까지는 변환기 없이 초기화한다(D8).

## 4. 인물 · 관계 · 적

### 4.1 인물(NPC) 2.0

```text
정체성: 이름·외형·종족·역할·소속 세력
내면:   성격·말투·가치관·목표(장기/단기)·두려움·비밀
지식:   Belief 목록 (구현됨) + 소문 퍼뜨리기 성향
기억:   대화 기억(구현됨) → 요약 기억(중요도·만료) 추가
관계:   플레이어와(4.2), 다른 NPC와(4.3), 세력과
행동:   일정(시간대별 위치), 목표 행동(5장 시계와 연결)
전투:   스탯블록 또는 직업+레벨, 카드, 전술 성향, 동료 조건
연출:   이미지(표정·상황 태그 — 구현됨), 음성(선택)
```

**역할(role)**에 따라 AI 연기 지침과 즉흥 범위 기본값이 달라진다: 주요 인물 `none`, 일반 `minor`, 행인 `free`(구현된 즉흥 범위와 연결).

### 4.2 플레이어와의 관계 2.0

- **축**: 호감·신뢰·존경·두려움(구현) + **친밀**(로맨스·우정의 깊이) + **원한**(적대가 쌓인 정도). 8축 원안 중 의존·경쟁은 성격 데이터로 대체.
- **관계 단계**: 축 조합으로 정의 — 낯섦 → 아는 사이 → 동료 → 친구 → 절친/연인 / 경계 → 적대 → 숙적.
- **관계 사건(Relationship Beat)**: 단계가 바뀔 때 엔진이 사건을 연다. 예: 신뢰 60 + 친밀 40 → "그가 비밀을 털어놓는다"(개인 퀘스트 시작).
- **로맨스**: `romanceable` 인물만. 콘텐츠 등급·장르 `tone.romance`를 따른다. 성인 등급(`mature`)에서는 노골적 묘사 허용, 공유 불가(15.1).
- **동료**: 영입 조건(구현) + **충성도**(관계에서 계산) — 낮으면 명령 거부·이탈, 높으면 개인 퀘스트·전용 카드.

### 4.3 NPC ↔ NPC 관계 그래프

- `relations: [{ a, b, kind: 'family'|'ally'|'rival'|'lover'|'master'|'enemy', strength }]`
- 쓰임: Actor 맥락("너는 X를 싫어한다"), 소문 전파 경로, 세력 행동, 플레이어 행동의 파급(한 사람을 도우면 그의 숙적의 원한 +).

### 4.4 세력 평판
- 세력별 -100~100. 의뢰 가능 여부, 상점 가격, 적대 조우 발동 조건, 결말 조건에 쓰인다.
- 조건 DSL에 `{ "reputation": "fac/…", "gte": 30 }` 추가.

### 4.5 적(Enemy) — 데이터 기반

```jsonc
{
  "id": "enemy/street-samurai", "name": "거리의 사무라이", "genre": ["cyberpunk"],
  "cr": 2, "role": "brute",            // brute | skirmisher | artillery | controller | leader | minion | boss
  "abilities": { "str": 14, "dex": 16, "con": 13, "int": 10, "wis": 11, "cha": 9 },
  "hp": "4d8+4", "ac": 15, "speed": 30,
  "cards": ["card/mono-blade", "card/reflex-dash"],
  "traits": ["pack_tactics"], "resist": ["slashing"],
  "behavior": { "focus": "lowest_hp", "flee_at": 0.25, "talk": true }, // 전술 AI + 대화로 해결 가능
  "loot": "loot/gang-common", "xp": 450,
  "image": { "tags": ["cyber", "street"] }
}
```

- **장르별 적 세트** 기본 제공: 장르마다 15~25종(일반 → 정예 → 보스). SRD 몬스터를 장르 외형으로 바꾼 것 + 자체 창작.
- **위협도 예산**: 조우는 "파티 레벨 × 인원" 예산 안에서 구성(쉬움·보통·어려움·치명). AI 생성 보조와 검사기가 이 예산을 쓴다.
- **보스**: 단계(phase)별 카드·대사·전장 변화. 처치 외 해결(설득·봉인·도주) 조건.
- **비전투 해결**: 모든 적에 `talk`·`flee_at`·`surrender` — 설득·위협·은신으로 전투를 피하거나 끝낼 수 있다(조우의 `resolution` 조건).

### 4.6 능력·카드
- 카드 = 효과 DSL(구현) + 장르 외형. 원천별 카드 묶음: 무기·비전·신성·초능력·기술·내공.
- 획득: 직업·레벨(구현) + 아이템·퀘스트 보상·관계(동료 전용)·세력.

## 5. 스토리 엔진 — 줄기 · 장 · 사건 · 시계

### 5.1 3층 구조

```text
줄기(Arc)        메인 줄기 1 + 세력 줄기 N + 인물 줄기 N
  └ 장(Chapter)   줄기의 큰 단계. 시작 조건 · 목표 · 끝 조건 · 실패 조건
      └ 사건(Beat) 장 안의 결정적 장면. 발동 조건 · 장소 · 등장 인물 · 선택지 · 결과(플래그·관계·지식·보상)
```

- 지금의 **임무 단계(QuestStage)** = "사건" 수준, **결말** = 줄기의 끝. v3는 그 위에 **장**과 **줄기**를 둔다.
- AI(Director)는 진행 중인 장의 **목표와 다음 사건 힌트**만 받는다(구현된 GM 힌트 방식 확장). 플레이어가 무시해도 세계는 5.3의 시계로 흘러간다.

### 5.2 분기
- 사건의 결과는 **플래그·관계·지식·세력 평판**으로 남고, 다음 장의 시작 조건이 이를 읽는다(조건 DSL).
- 분기는 "선택지 트리"가 아니라 **상태 기반**: 같은 장이 다른 상태에서 다르게 열린다. 제작 부담을 줄이고 자유 입력과 잘 맞는다.

### 5.3 진행 시계 (Clocks / Fronts)

플레이어가 행동하지 않아도 세계가 움직이게 하는 핵심 장치.

```jsonc
{ "id": "clock/rebellion", "name": "반역 준비", "segments": 8, "owner": "fac/daphneya",
  "tick": [ { "every": "day", "by": 1 }, { "on": { "flag": "player_warned_guard" }, "by": -2 } ],
  "at": { "4": "beat/rumors-in-court", "8": "beat/the-coup" } }
```

- 시간·사건·플레이어 행동으로 칸이 차고 줄어든다. 특정 칸에서 사건이 열린다.
- 카드 세계의 **연표·D-day**(구현된 달력)는 날짜 기반 시계로 바로 옮긴다: "429년 9월 21일 → 반역 사건".
- 플레이어에게는 **징조**로만 보인다(소문·분위기·NPC 행동). 수첩에 "불길한 기운" 정도만.

### 5.4 연표 사건 (World Events)
- `events: [{ id, when: { day | condition }, effects: [...], visibility }]`
- 효과: 장소 상태 변경, NPC 이동·사망·태도 변화, 세력 관계, 새 퀘스트, 지식 공개(소문 퍼짐).
- 원작 사건을 **바꿀 수 있는 미래**로 다룬다: 플레이어가 조건을 바꾸면(플래그) 사건이 바뀌거나 사라진다.

### 5.5 연출 템포 (Pacing)
- 장마다 목표 긴장도. 최근 턴의 전투·사교·탐험 비율과 긴장을 보고 Director에게 "다음엔 휴식/위기/단서" 힌트(구현된 GM 안내와 연결).

## 6. 미션 · 퀘스트

### 6.1 퀘스트 유형 (12)

| 유형 | 완료 조건 예 (엔진 판정) | 실패 예 |
|---|---|---|
| 토벌 hunt | `cleared: enc/…` / `defeated: enemy/…` × n | 시간 초과 |
| 호위 escort | 대상 `inParty` + `at: 목적지` | 대상 사망 |
| 전달 deliver | `hasItem` + `at` + 받는 이와 대화 | 아이템 분실 |
| 수집 gather | `hasItem` × n | — |
| 조사 investigate | `knows: claim/…`(단서 n개) | 증거 인멸 시계 완료 |
| 잠입 infiltrate | `at` + `not detected`(경보 시계) | 경보 |
| 구출 rescue | 대상 `inParty` + 탈출 | 시계 완료 |
| 방어 defend | 시계가 끝날 때까지 장소 유지 | 장소 함락 |
| 협상 negotiate | 관계·평판 조건 + 플래그 | 적대 |
| 생존 survive | 날짜 도달 + 생존 | 사망 |
| 결투 duel | 1대1 승리(규칙 제한) | 패배 |
| 관계 bond | 관계 단계 도달·관계 사건 | 원한 |

→ 조건 DSL 추가: `hasItem`, `defeated`, `reputation`, `day`(날짜 이후), `clock`(시계 칸), `npcAlive`, `npcAt`, `meter`(스트레스 등).

### 6.2 퀘스트 구성

```jsonc
{ "id": "quest/lost-rope", "type": "rescue", "giver": "npc/mokryeon", "arc": "arc/sinkhole",
  "start": { … }, "stages": [ { "objective", "hint", "complete", "fail" } ],
  "timeLimit": { "days": 3 }, "rewards": { "xp": 200, "money": 50, "items": [], "cards": [], "reputation": [], "relationship": [] },
  "repeatable": false }
```

### 6.3 의뢰판 (Job Board) · 템플릿
- **템플릿**: `{유형} × {의뢰인 세력} × {장소} × {적 세트}` 조합으로 **반복 의뢰**를 생성. 카드 세계의 "의뢰감" 로어(도시 · 여덟 구역 카드 등)를 템플릿 재료로 쓴다.
- 의뢰는 평판·등급(예: 해결사 급수)으로 열린다. 보상은 위협도 예산과 연동.
- AI 생성 보조는 **템플릿을 채우는 일**만 하고, 조건·보상은 엔진 규칙이 정한다.

### 6.4 보상 · 경제
- 소지금·상점(가격 = 기본가 × 평판 보정)·전리품 표(`loot/…`)·장비가 AC/공격에 반영.
- 인벤토리 UI, 아이템 효과 DSL(회복·버프·카드 부여·열쇠).

## 10. 패키지 생태계 (서버 없이)

| 종류 | 확장자 | 내용 | 지금 |
|---|---|---|---|
| World | .wpk | 세계·장소·인물·세력·지식·연표·장르 | ✓(세력·장르 제외) |
| Scenario | — | 분리하지 않음(D7): 세계 안에 줄기를 계속 추가 | 세계 안에 포함 |
| Character | .chp | 인물 + 관계 템플릿 + 이미지 + 스탯 | — |

- 공유: 파일만(D5). 성인 등급·카드 기반 세계는 공유 불가, 기기 간 이동만.
- 개인용 패키지(타인 작품 기반)는 공유 불가·기기 이동만(구현).

### 15.1 성인 등급 정책 (D6)
- `contentRating: "mature"`인 세계에서만 적용: 서술·NPC·세계 생성 AI에게 잔혹하고 노골적인 묘사(폭력·성적 묘사 포함)를 허용한다고 알린다. 카드를 가져올 때 노골적인 줄도 빼지 않는다.
- **어떤 등급에서도 금지**: 미성년자(또는 미성년자로 보이는 인물)가 관련된 성적 내용, 실존 인물의 성적 묘사.
- **공유 불가**: 성인 등급 세계는 `.wpk` 내보내기·세이브 내보내기가 막힌다. 내 다른 기기로는 옮길 수 있다 (카드 세계는 카드 열쇠, 직접 만든 세계는 암호 열쇠).
- **성인 확인**: 성인 등급을 고르거나 성인 등급 세계를 플레이할 때 처음 한 번 확인한다 (이 브라우저에 기억).
- AI 제공자의 이용 정책에 따라 모델이 일부 요청을 거절할 수 있다. 이는 사용하는 AI 설정(모델·제공자)에 달려 있다.

### 15.3 이야기 추가 구조 (D7)
- 한 세계 안에 **줄기(Arc)를 여러 개** 둔다. 편집기의 "AI로 이야기 추가"는 새 줄기(장·사건·퀘스트·결말)를 덧붙인다.
- 각 줄기는 시작 조건으로 열리며, 줄기끼리 플래그로 이어질 수 있다 (예: 1부 결말 → 2부 시작).

### 15.4 초기화 정책 (D8)
- v1 완성 전에는 스키마가 바뀌는 릴리스에서 이전 세계·세이브가 열리지 않을 수 있다. 그런 릴리스는 변경 기록에 **초기화 필요**를 표시하고, 앱이 이전 데이터를 발견하면 알린다.
