# WORLDFORGE 설계안 v4 (초안) — 성장 · 보상 · 몰입

> 작성 2026-11-06 · 기준 버전 v0.37.11
> 입력: 사용자 제공 문서 2편 (「스토리·퀘스트 설계」, 「하이판타지·무협·로맨스 세계관 패키지」) + `design-v3.md` + 현재 코드
> 목표: **"점점 강해지는 주인공"을 체감하고, 계속 하고 싶고, 지루해지지 않는 게임.**
> 결정(2026-11-06): 9장의 추천안대로 확정 — 혼합 성장 · 보통 속도 · 5등급+유물 · 등급 사다리 도입 · 표시 수준 기본 · 적응 난이도 켬.

## 0. 요약

- **뼈대는 이미 있다.** 첨부 문서가 제안하는 구조(5계층 스토리, 사건 중심 퀘스트, 세계 상태 연결, 관계 엔진, 세력 시뮬레이션, 장르 패키지)는 v3에서 대부분 구현됐다 (1장 대응표).
- **아쉬운 이유는 "보상과 체감"이 비어 있기 때문이다.** 시스템은 세계를 움직이지만, 플레이어에게 *돌아오는 것*이 약하고 *보이지 않는다*.
  1. **성장이 멈춘다.** 퀘스트 보상은 75~200 XP인데, 레벨 4→5는 3,800 XP, 5→6은 7,500 XP다. 이야기 중심으로 플레이하면 **3~4레벨에서 사실상 정체**된다.
  2. **얻는 것이 단조롭다.** 아이템 19종이 모두 평범한 장비·물약이다. 등급·마법 장비·유물·수집 요소가 없다.
  3. **강해진 것이 보이지 않는다.** 레벨업은 기록 한 줄이고, 세계(NPC·적·소문)가 주인공의 성장에 반응하지 않는다.
  4. **다음에 할 이유가 약하다.** 세션을 마칠 때 남는 떡밥·예고·"다음 목표"가 화면에 없다.
- **v4는 다섯 기둥으로 보강한다.** P1 성장 곡선 · P2 보상 다양화 · P3 체감과 세계의 반응 · P4 몰입 루프와 세션 훅 · P5 변화와 긴장(지루함 방지). 원칙은 그대로 둔다: **보상과 판정은 엔진이 정하고, AI는 그것을 연출한다.**

### 1.2 「세계관 패키지」

| 첨부 문서 제안 | 현재 구현 | 상태 · 남은 것 |
|---|---|---|
| 공통 세계 규격 + 장르 데이터 | 장르 프로필 + 리스킨 + 규칙 팩 | ✅ |
| 하이판타지·무협·로맨스 패키지 | 샘플 3개 (각 장소 3~6, 인물 3~5) | 🟡 **내용 규모가 작음** (문서 목표: 지역 10·인물 30·퀘스트 30) → 6장 |
| 무협 경지 (삼류 → 생사경), 레벨과 별도 | 무협은 레벨을 "내공 n성"으로 리스킨 | 🟡 **별도 등급 사다리** 없음 → P3 (등급) |
| 로맨스 관계 8변수 · 7단계 | 6축(호감·신뢰·존경·두려움·친밀·원한) + 단계 + 관계 사건 | ✅ 질투·애착은 성격·사건으로 대신 |
| NPC가 먼저 다가옴, NPC끼리 관계 변화 | 관계 사건(엔진이 열면 AI가 연출), NPC↔NPC 관계는 고정 | 🟡 **먼저 찾아오기**, **NPC끼리 관계 변화** → 4.4 |
| 장르 확장 패키지 (Romance.Extension 등) | 인물 패키지 .chp · 규칙 패키지 .rule, 이야기는 세계 안에 줄기로 (D7) | ✅ D7 유지. "확장 = 줄기 묶음 + 인물 + 규칙"으로 충분 |
| 원본은 수정하지 않고 확장, 고유 ID, 버전 고정 | 복제해서 편집, ID 규칙, 세이브에 패키지 버전 기록 | ✅ |

**결론:** 구조 쪽 개선은 작다 (퀘스트 결과·세계 수치·돌발 사건·NPC 목표). **큰 개선 여지는 성장·보상·체감·세션 경험**이다. v4의 대부분은 여기에 쓴다.

## 2. 설계 원칙 (v4 추가)

1. **보상은 엔진이 정하고, AI는 연출한다.** 아이템·경험치·칭호는 데이터와 규칙으로만 생긴다. AI가 "전설의 검을 얻었다"고 써도 엔진이 주지 않았으면 없다 (지금처럼).
2. **자주, 작게, 가끔 크게.** 매 턴 작은 피드백, 몇 턴마다 눈에 띄는 보상, 장마다 큰 보상.
3. **강해진 것은 숫자보다 세계가 말해 준다.** 예전에 도망치던 적이 길을 비키고, 마을 사람이 당신 이름을 안다.
4. **다음이 궁금해야 끝낼 수 있다.** 세션을 마칠 때 떡밥 하나와 할 일 세 갈래가 남아야 한다.
5. **게임스러움은 고를 수 있게.** 숫자·업적 알림을 좋아하는 사람과 소설처럼 읽고 싶은 사람 모두를 위해 표시 수준을 설정으로 둔다.

## 3. 다섯 기둥

### P1. 성장 곡선 — "주인공이 계속 강해진다"

**문제:** SRD 경험치 표는 "한 레벨에 보통 조우 6~12번"을 가정한다. 우리 게임은 대화·조사 비중이 커서 전투 경험치가 적고, 퀘스트 보상(75~200 XP)은 표의 뒷부분과 맞지 않는다.

**제안: 혼합 성장 (경험치 + 이정표)**

| 출처 | 지금 | 제안 |
|---|---|---|
| 전투 | 몬스터 XP 합 ÷ 인원 | 유지 |
| 새 사실 발견 | 25 XP | **현재 레벨 기준 비율** (다음 레벨까지의 1%, 최소 25 — 레벨 5: 75) |
| 퀘스트 완료 | 제작자가 정한 고정값 | **"레벨 비율" 보상**: `xp: "minor" / "major"` → 다음 레벨까지 필요한 양의 10% / 25%. 고정 숫자는 최소 8% |
| 관계 단계 상승 | 없음 | 처음 도달한 단계마다 4% |
| 어려운 판정 성공 | 없음 | DC 15 이상 2%, DC 20 이상 4% — "잘한 플레이"에 보상 |
| 장(Chapter) 완료 | 없음 | **이정표 레벨업**: 장을 끝내면 최소 1레벨 보장 (세계 상한까지) |

- **초반 가속**: 1레벨 ×2.5, 2레벨 ×2 (비율 보상에만).
- **목표 속도** (조정 가능): 1→2레벨 10~15턴, 2→3 20턴, 이후 레벨마다 30~50턴. 장 하나에 1~2레벨.
- **구현 (v0.38.0)**: 엔진만으로 굴린 300턴 시뮬레이션 — 50턴마다 3·5·6·8·9·10레벨, 첫 레벨업 15턴 (`growth.test.ts`).
- 제작자는 숫자를 몰라도 된다: 편집기에서 "작은 보상 / 큰 보상 / 장 완료"만 고르면 엔진이 레벨에 맞춰 계산한다 (기존 고정 XP도 그대로 지원).
- 의뢰판 보상도 같은 방식 (지금은 위협도 기반 → 레벨 비율과 섞음).

### P2. 보상 다양화 — "얻는 것이 매번 조금씩 다르다"

**2-1. 아이템 등급과 마법 장비**

| 등급 | 색 | 예 | 얻는 곳 |
|---|---|---|---|
| 일반 | 회색 | 롱소드, 물약 | 상점·전리품 |
| 고급 | 초록 | 정교한 롱소드(+1 명중) | 전리품·의뢰 |
| 희귀 | 파랑 | +1 롱소드, 화염 저항 망토 | 정예·퀘스트 |
| 영웅 | 보라 | 카드가 붙은 장비 ("번개 일격" 카드) | 보스·장 완료 |
| 유물 | 금색 | **이름 있는 성장형 유물** (2-2) | 줄기 보상 1~2개 |

- 아이템 스키마에 `rarity`, `bonus: { attack?, damage?, ac?, save? }`, `cards?: string[]`, `resist?` 추가. 효과는 기존 효과 DSL과 전투 훅으로만 (코드 실행 없음).
- **전리품 표**: `loot: { table: "loot/forest-t1" }` → 등급 가중치 표에서 굴림. 보스는 "확정 1개 + 굴림".
- 장르 리스킨: 무협은 "비급·영약·보검", 로맨스는 "선물·추억의 물건"(관계 보너스가 붙은 장신구).

**2-2. 성장하는 유물 (Signature Item)**
- 이야기에 묶인 장비 하나가 주인공과 함께 강해진다: 줄기 진행·관계·업적 조건으로 **각성 단계**가 열린다 (예: 녹슨 검 → 이름을 되찾은 검 → 깨어난 검).
- 각성마다 카드·보너스·서술 태그가 바뀐다. "강해짐"을 장비 하나로 오래 느끼게 하는 장치.

**2-3. 기술·무공 습득 보상**
- 카드 보상(구현됨)을 "**비급·주문서·가르침**" 아이템으로 확장: 얻고 → 익히는 데 휴식 n번 → 카드 획득. 무협의 "비급 발견 → 수련 → 습득"을 그대로 담는다.
- 스승 NPC에게 관계 조건으로 배우기 (관계 보상).

**2-4. 관계 보상 (구현 확장)**
- 단계별 혜택을 데이터로: 친구 — 상점 할인/정보, 절친·연인 — 전용 카드·지원 행동, 숙적 — 적대 조우 (이미 일부 구현된 전용 카드·영입 조건과 연결).

**2-5. 수집 (Collection)**
- **도감**: 만난 적·가 본 장소·만난 인물·알게 된 사실 (대부분 이미 기록에 있다 → 화면만 만들면 됨).
- **결말 수집**: 세계별로 본 결말 표시 (다회차 동기).

### P3. 체감과 세계의 반응 — "강해진 것이 보인다"

**3-1. 명성(Renown)과 칭호**
- 행동 기록에서 엔진이 **칭호**를 준다: "늑대 사냥꾼"(늑대 10마리), "미스트베일의 은인"(퀘스트), "독사의 원수"(숙적). 데이터: `titles: [{ id, name, condition }]` — 조건은 기존 조건 DSL(`defeated`, `questDone`, `reputation`…).
- **명성 수치**(세계 공통 또는 지역별): 퀘스트·칭호·업적으로 오른다. NPC Actor 맥락에 "이 인물은 당신을 ○○로 알고 있다"를 넣어 **NPC가 먼저 알아본다.** 소문 전파(구현)에 명성 소문을 태운다.

**3-2. 등급 사다리 (장르별 "격")**
- 레벨과 별도로 이름 붙은 **등급**: 하이판타지 "모험가 등급 F→S", 무협 "삼류 → 이류 → 일류 → 절정 → 초절정 → 화경 → 현경 → 생사경", 로맨스 "사교계 평판".
- 등급 = 레벨 + 명성 + 특정 시험(승급 퀘스트·결투). 오르면 의뢰판 상위 의뢰·지역·인물이 열린다. 첨부 문서의 "경지는 레벨과 별도 데이터"를 따르되, 엔진 규칙은 d20 그대로 (D1 유지).

**3-3. 예전 적의 재등장 (압도 연출)**
- 초반 적(늑대·산적)이 후반에 다시 나오면 **위협도 표시가 "쉬움"** 이 되고, 적이 도망·항복(구현된 도망·대화 해결)할 확률이 오른다. 서술 AI에게 "주인공이 이 적에게는 압도적" 힌트.
- 선택: "일격 정리" — 위협도가 아주 낮은 조우는 전투 화면 없이 판정 한 번으로 정리.

**3-4. 성장 연출**
- **레벨업 화면**: 오른 능력치·새 카드(카드 그림·효과 미리보기)·하위 직업/특성 선택(구현)을 한 화면에.
- **전리품 화면**: 등급 색·획득 연출·"장비하기" 버튼.
- 전투 기록에 "처음으로 ○○을 이겼다" 같은 **첫 경험 표시**.

### P4. 몰입 루프와 세션 훅 — "계속 하고 싶다"

**4-1. 세 겹의 루프**

```text
한 턴     행동 → 판정 → 결과 연출 → 작은 피드백 (♡ 관계 변화, 알게 된 것, XP 조각)
한 사건   단서·조우·대화 3~8턴 → 사건 해결 → 보상 (아이템·관계·칭호 진행)
한 장     사건 3~6개 → 장 완료 → 이정표 레벨업 · 유물 각성 · 새 지역 · 세계 변화 요약
```

**4-2. 세션 훅**
- **이어하기 요약 ("지난 이야기")**: 세이브를 열면 마지막 장면·미해결 실마리·현재 목표를 3줄로 (엔진 기록 + 짧은 AI 요약).
- **떡밥 목록 ("궁금한 것")**: 알게 된 단서 중 아직 풀리지 않은 것을 수첩에 (주장·발견 데이터 기반). "왜 제단의 재는 새것이었을까?"
- **할 일 세 갈래**: 수첩 맨 위에 메인 · 사이드 · 관계 목표 하나씩 (GM 안내의 선택지와 연결).
- **장 끝 예고**: 장을 마치면 다음 장 제목과 한 줄 예고 (제작자 데이터, 없으면 AI).

**4-3. 피드백 표시 수준 (설정)**
- `몰입형` — 숫자 최소, 서술 속에 녹임 / `기본` — 지금처럼 / `게임형` — XP 막대·업적 알림·칭호 토스트. (원칙 5)

### P5. 변화와 긴장 — "지루해지지 않는다"

**5-1. 돌발 사건 표 (Event Director)**
- 장소·지역·시간대별 **사건 표**: `{ id, weight, cooldownDays, condition, kind: 'encounter'|'meeting'|'news'|'opportunity', effects }`.
- 이동·휴식·대기 때 엔진이 굴린다 (지연 시뮬레이션과 같은 자리). 여관에서 소식, 길에서 습격, 떠돌이 상인, 도움 요청.
- AI 세계 생성이 장르·지역에 맞는 표를 함께 만든다.

**5-2. 템포 감독 강화 (구현 확장)**
- 지금: 최근 활동 비율로 Director에게 힌트. 추가: **단조로움 감지** (같은 종류 n턴 연속, 보상 없는 턴 n번) → 돌발 사건 확률 상승 또는 "단서 주기" 힌트.

**5-3. 적응 난이도 (선택)**
- 연속 패배·빈사 → 다음 조우 완화, 회복 아이템 전리품 가중. 연속 압승 → 정예 변형 등장 (적 스탯 +, 보상 +). 설정에서 끌 수 있음.

**5-4. 선택의 대가가 보이게**
- 결정적 선택(구현) 결과를 **장 완료 요약**에 "당신의 선택이 바꾼 것"으로 보여 준다 (세계 수치 변화, 인물 생사, 평판).

## 4. 구조 보강 (첨부 문서에서 가져올 것)

### 4.1 원칙
- 새 엔티티를 늘리기보다 **기존 스키마에 칸을 더한다** (D8: v1 전 호환 없음이라 자유롭지만, 제작 도구 부담을 줄이려고).

### 4.2 퀘스트 2.1 — 접근법 · 숨은 진실 · 여러 결과

```jsonc
{
  "id": "quest/missing-children", "type": "investigate",
  "motive": "아이를 잃은 부모의 부탁",              // 동기 (Director·안내가 씀)
  "approaches": [                                  // 접근법 (AI 힌트 + 판정 기술)
    { "id": "track",  "hint": "숲의 흔적을 쫓는다", "skills": ["survival", "perception"] },
    { "id": "question", "hint": "주민 증언을 비교한다", "skills": ["insight", "persuasion"] },
    { "id": "sneak",  "hint": "촌장 집에 잠입한다", "skills": ["stealth"], "risk": "들키면 촌장 평판 -" }
  ],
  "truth": "claim/elder-pact",                     // 숨은 진실 (주장 ID — 지식 시스템이 지킨다)
  "clues": ["claim/fresh-ash", "claim/elder-night-walk"],
  "outcomes": [                                    // 여러 결과 (위에서부터 처음 맞는 것)
    { "id": "exposed", "when": { "all": [{ "knows": "claim/elder-pact" }, { "flag": "told_village" }] },
      "effects": [ { "var": "region/mistvale.order", "add": -20 }, { "killNpc": … } ], "rewards": { "xp": "major", "title": "진실을 밝힌 자" } },
    { "id": "deal", "when": { "flag": "kept_secret" }, "effects": [ … ], "rewards": { "xp": "minor", "item": "…" } }
  ],
  "followUps": ["quest/new-elder-election"]       // 후속 (결과에 따라 열림)
}
```

- 지금의 단계(stages)·실패·기한·보상은 그대로 두고 **선택 칸**으로 추가한다. 조사형 퀘스트에서 "정답이 하나가 아닌" 구조를 데이터로 표현.

### 4.3 세계 수치 (World Variables)
- 지역·세력에 숫자 상태: `vars: { "region/mistvale.order": 70, "region/forest.danger": 40 }`.
- 효과 `{ var, set | add }`, 조건 `{ var, gte | lte }` 추가. 시세(상점 가격), 조우 확률(돌발 사건 표 가중치), 서술 분위기(장면 맥락)에 쓴다.
- 플레이어에게는 숫자 대신 단계 이름으로 ("치안: 불안"). 장 완료 요약에 변화 표시.

### 4.4 NPC 목표 · 먼저 다가오기 · NPC끼리의 관계 변화
- **NPC 목표**: `goals: [{ id, text, clock?, done: condition }]` — 시계(구현)로 시간이 지나며 진행, 끝나면 효과. 주요 NPC 몇 명만.
- **먼저 다가오기**: 관계 사건(구현)이 열리면 그 NPC가 **플레이어가 있는 곳으로 찾아오거나 전갈**을 보낸다. 지금은 플레이어가 그 인물과 대화할 때만 연출되고, 다른 곳에 있으면 정해진 턴이 지나 **보지도 못한 채 닫힌다**.
- **NPC끼리 관계 변화**: 지연 시뮬레이션에서 같은 장소·세력 NPC의 관계를 조금씩 움직이고(가중치 낮게), 큰 변화는 소문으로.
