# 캐릭터 카드 세계의 이미지가 서술과 어울리지 않는 이유 (v0.118 기준 분석 · v0.119 개선)

## 증상
등장인물은 맞지만 표정·행동이 장면과 어울리지 않고, 카드에 표정·상황별 이미지가 많아도 다양하게 나오지 않는다. RisuAI에서는 같은 카드의 이미지가 서술과 잘 맞는다.

## 원인 (코드에서 확인)

| # | 원인 | 위치 |
|---|---|---|
| 1 | **AI가 이미지를 고르지 않았다 (v0.118 한 번 호출 턴).** 예전 정확 모드에서는 NPC 연기 AI가 표정 태그(`expression`)를, GM 판단 AI가 장면 태그(`scene_image`)를 골랐다. 한 번 호출 턴으로 바꾸면서 이 두 칸이 없어져, 이미지는 엔진의 짐작만으로 골라졌다 | `gm/turn.ts` `turnImagesFor` (speakers 없이 호출) |
| 2 | **엔진의 짐작이 너무 좁다.** 서술에서 그 인물이 나온 문장을 정규식으로 보고 9가지 감정(웃음·분노·슬픔·놀람·걱정·진지·홍조·피곤·부상)만 알아본다. 카드의 태그가 행동·상황(먹기·잠·싸움·포옹·옷차림·밤…)이면 서술로는 절대 골라지지 않고, 기본 이미지로 떨어진다 | `engine/assets.ts` `EXPRESSIONS` · `contextExpression` |
| 3 | **그림의 자리가 "이름이 처음 나온 문단"으로 고정된다.** 인물당 한 턴에 한 장, 이름이 나온 문단 앞. 표정이 바뀌는 문단에 다시 놓이지 않는다 | `gm/turn.ts` `turnImages` |
| 4 | **RisuAI는 모델이 고른다.** RisuAI 카드는 보통 프롬프트에 이미지 이름 목록을 주고, 모델이 문장 사이에 이미지 표시를 직접 넣는다(인레이 에셋 · 감정 이미지). 서술을 쓰는 손이 그림도 고르니 어울린다. 우리 앱은 카드의 이 지시를 쓰지 않고 이름 규칙으로만 인물·태그를 붙였다 | `importers/assetmatch.ts` |
| 5 | (부수) AI 이미지 분류는 이미지마다 태그를 3개까지만 남긴다 | `importers/assetmatch.ts` |

## v0.119에서 바꾼 것
- **AI가 서술 속에서 그림을 고른다** (`gm/imageMarks.ts`): 한 번 호출 턴의 프롬프트에 이 자리 인물별 태그 목록(최대 40개)과 장소의 장면 태그를 주고, AI가 그림이 어울리는 문단 앞에 `[[그림 인물ID 태그]]` · `[[배경 태그]]`를 쓴다. 엔진은 표시를 글에서 지우고 실제 이미지로 바꾼다(같은 뜻의 태그 포함). 표정이 바뀌는 문단마다 같은 인물이 다른 그림으로 나올 수 있다 (한 턴 6장까지).
- 표시가 없으면 예전처럼 엔진이 짐작한다.

## 남은 것 (다음 후보)
- 정확 모드·전투·장면 뒤 서술에도 같은 표시를 쓰게 하기 (지금은 NPC 연기 AI의 표정과 엔진의 짐작).
- 카드의 이미지 사용 지시(에셋 이름 목록·감정 이름)를 가져올 때 읽어 태그로 살리기.
- AI 이미지 분류의 태그 수(3개) 늘리기.
