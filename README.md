# WORLDFORGE

사용자가 만든 세계관에서 AI가 GM·서술자가 되어 주는 1인칭 텍스트 RPG — **서버 없이 브라우저에서 단독 실행**되는 싱글플레이 게임이자, 그 세계관을 만드는 **제작 도구**.

- 웹: GitHub Pages (`main` 브랜치에 푸시하면 자동 배포)
- 오프라인: `worldforge-offline.html` 한 파일을 받아 더블클릭으로 실행 (`file://`)
- AI: 사용자 본인의 API 키(BYOK) — Claude, 그리고 OpenAI 호환 주소면 무엇이든 (OpenAI · OpenRouter · Ollama · LM Studio 등). 제공자를 여럿 등록하고 역할(서술·판단·생성 등)마다 모델을 따로 고를 수 있다
- AI 없이도: 갈래 카드가 있는 세계(내장 「에테리아」)는 API 키 없이 선택지로 체험할 수 있다
- 저장: 브라우저 IndexedDB (세계·세이브·이미지·초안) + 파일 내보내기/가져오기

현재 버전과 바뀐 점은 [`CHANGELOG.md`](CHANGELOG.md)에 있다.

## 플레이

```
선택(갈래 카드의 갈림길 · 결정적 선택 · 걸린 것) 또는 자유 입력
  → 엔진: 후폭풍 · 판정 3단(성공 · 대가 있는 성공 · 실패하되 전개) · 규칙 · 임무·국면 · 다음 카드 · 미리 굴린 주사위
  → AI 1번 (서술 스트리밍 → 끝에 판정 선언 · 알려 준 것 · 마음의 움직임 · 이동/전투/장면 요청 · 선택지)
  → 엔진이 AI의 응답을 검증해 적용
```

- **한 번 호출 턴** (v0.118~): 판단·대사·서술·선택지를 AI 한 번에. 예전 방식(GM 판단 → 인물별 연기 → 서술)은 플레이 설정 「정확 모드」로 남아 있다.
- **엔진이 사실을 지킨다**: 이벤트 소싱 상태(되돌리기·리플레이), 지식 필터(플레이어·인물이 모르는 것은 프롬프트에 넣지 않는다), 조건식 시나리오(임무·결말·플래그·연표 사건·진행 시계·세계 규칙).
- **SRD 5.2.1 기반 규칙**: 능력치·기술 판정, 존 기반 카드 전투, 동료, 장면(협상·추격·의식 등 비전투 상호작용), 함정·퍼즐.
- **그림**: 인물·장소마다 여러 장, 태그(표정·상황·시간·날씨)로 장면에 맞는 그림을 고르고, 서술 중에 보인 그림은 끝까지 고정한다.
- **프롬프트 캐싱**: Claude는 긴 시스템 프롬프트와 세계 개요에 캐시 표시, OpenAI 호환은 제공자 캐시를 기록한다. 사용량 화면에서 비용·캐시 비율을 본다.

## 세계관 제작

편집기는 **🗺 흐름도**가 중심이다 (v0.142~).

- **흐름도**: 임무·결말·갈래 카드·결정적 선택·장면·함정·퍼즐·전투·줄기·연표 사건·진행 시계·세계 규칙·플래그·지식, 그리고 아래 띠의 장소·인물·세력·아이템·적이 상자로, 그 사이의 조건·효과가 화살표로 보인다. ▶ 플레이 시작에서 오른쪽(또는 아래)으로 흘러 결말에 이른다.
  - 상자를 누르면 옆 창(휴대폰은 아래)에서 그 자리에서 고친다 — 임무는 단계별로, 장면은 수치·행동까지, 함정·퍼즐·카드·선택·전투·세력·인물 관계까지. ▶ 시작 상자에서 시작 장소·소지품·시작 방식·주인공 양식·직업.
  - 상자의 ● 손잡이를 다른 상자로 끌어 **잇고**, 화살표를 눌러 **연결 조건을 고치고**, 상자를 끌어 **자리를 옮긴다**. 📋 목록 · 미니맵 · 찾기 · 종류 거르기.
  - **🧪 시뮬레이션**: AI 없이 실제 엔진 규칙으로 진행해 보고(🔒 잠김 · 🟢 열림 · ✔ 끝남 · 🏁 결말), 잠긴 까닭을 조건마다 ✓/✗로 본다. 결정적 선택은 고르면 어떻게 되는지 미리 보고, 성향·관계·평판·수치를 정해 시험한다. **🎲 자동 탐색**은 무작위로 100번 끝까지 해 보고 결말 비율·한 번도 열리지 않은 상자·막힌 판·선택지별 결말을 알려 준다.
- **⚙ 세계 설정 · 📋 항목별 편집**: 예전처럼 종류별 탭으로도 고친다 (기본·세계 규칙·주인공·직업·관계·지식 / 임무·이야기 흐름·장면·함정·조우·아이템·장소·인물).
- **만드는 다른 길**: 🧭 마법사(단계별 도우미) · ✦ AI로 세계관 만들기 · ✦ 캐릭터 카드로 만들기(CHARX · RisuAI 모듈 · PNG · JSON — 카드 스크립트에서 그림 연결을 읽는다) · 🌌 만계서고에서 크로스오버.
- **🌌 만계서고 · ⭐ 내 에셋**: 만들어 둔 모든 세계의 인물·장소·임무·카드 등을 딸린 것·그림과 함께 복사해 온다. 흐름도 상자를 「⭐ 에셋으로 보관」하면 어느 세계에도 속하지 않은 보관함에 모이고, 흐름도의 「🌌 만계서고에서 가져오기」로 고른 상자 다음에 이어 붙인다.
- **초안**: 편집 중인 내용은 저절로 초안으로 보관되어 앱이 꺼져도 이어서 고치고, 저장본과 갈라진 초안은 세 갈래로 합친다.
- **🧪 시험**: 상태 시험대 · 자동 플레이·전체 점검 · 보드·지도·시뮬레이터 · 장면 시험(자동 200회).

## 개발

```bash
npm install
npm run dev            # 개발 서버
npm test               # 단위 테스트 (vitest)
npm run typecheck      # 타입 검사 (tsc -b — 테스트 파일 설정까지 본다)
npm run build          # dist/        → GitHub Pages용
npm run build:single   # dist-single/ → 단일 index.html (file:// 실행용)
npm run ui:audit       # 화면 자동 점검 (Playwright: PC 1280px·모바일 390px — 가로 넘침·작은 터치 대상·16px 미만 입력칸·페이지 오류)
```

작업 규칙(릴리스 절차, 타입 검사, UI 사전 점검 기준)은 [`CLAUDE.md`](CLAUDE.md)에 있다. `ui:audit`은 `build:single` 결과를 쓴다 — 화면 하나만: `npm run ui:audit -- --only 장면`, 스크린샷: `-- --shots 폴더`.

## 릴리스

`package.json`의 `version`을 올리고 `CHANGELOG.md` 맨 위에 같은 버전 섹션을 추가해 `main`에 푸시하면,
GitHub Actions가 `npm test` 후 `vX.Y.Z` 태그와 GitHub Release를 만들고 오프라인 HTML을 첨부한다.

## GitHub Pages 설정 (최초 1회)

저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 지정한다.
공개 저장소는 무료, 비공개 저장소의 Pages는 유료 플랜이 필요하다.

## 로컬 모델 사용

브라우저에서 로컬 서버를 호출하려면 CORS 허용이 필요하다.

- Ollama: `OLLAMA_ORIGINS=* ollama serve` → Base URL `http://localhost:11434/v1`
- LM Studio: 개발자 서버 설정에서 CORS 활성화 → Base URL `http://localhost:1234/v1`

## 보안 메모

- API 키는 사용자 브라우저에만 저장되며, 이 저장소나 서버로 전송되지 않는다. 키를 코드나 커밋에 넣지 말 것.
- GitHub Pages에서는 같은 `*.github.io` 출처의 다른 페이지와 브라우저 저장소를 공유한다. "키 기억하기"를 끄면 탭을 닫을 때 삭제된다.

## 라이선스

WORLDFORGE는 **GPL-3.0-or-later**로 배포한다 (`LICENSE`, `NOTICE`).

- RisuAI 모듈(.risum)·CHARX 형식은 RisuAI(GPL-3.0)의 `src/ts/process/modules.ts`를 따라 읽는다.
- `src/vendor/rpack/`의 rpack 해독 표는 RisuAI의 Rpack(© Kwaroran)에서 옮겼다. 원본은 RisuAI 안에서만 MIT이고 그 밖에서는 AGPL-3.0이므로, 이 부분은 **AGPL-3.0**으로 배포한다 (GPLv3 13조에 따라 결합 가능). 원본 라이선스 파일을 함께 둔다.
- 웹 버전(GitHub Pages)과 오프라인 HTML 모두 상단의 **소스 (GPL)** 링크로 소스 코드를 받을 수 있다.

### 다른 사람의 캐릭터 카드 (리소스별 개인용)

다른 사람의 캐릭터 카드(CHARX 등)에서 온 것은 **리소스 단위로 출처를 기록**한다 (v0.157~). 앱은 카드 파일 자체가 아니라 카드 지문과 그 카드에서 온 인물·지식·그림 등의 목록을 저장한다.

- 라이선스 표시가 없는 카드(라이선스 모름 = 모든 권리는 제작자에게)에서 온 것은 **개인용** — 이 브라우저에서는 그대로 쓰고, 내보낼 때는 그것만 빼고 내보낸다(「개인용 빼고 내보내기」). 세계 전체를 카드로 만든 경우는 뺄 수 없어 이 브라우저에서 혼자만 플레이할 수 있다.
- 제작자가 라이선스(예: CC BY)로 허락한 카드는 「기본」 탭의 출처 카드에서 표시하면 잠그지 않고, 출처 표시가 세계와 함께 간다. 표시는 기록일 뿐 권리를 만들지 않는다 — 허락을 확인하는 것은 표시하는 사람의 몫이다.
- 기기 사이 이동은 원본 카드 파일로 잠근 파일로 한다. 카드와 그림의 저작권은 원작자에게 있다. (브라우저 안에서 동작하는 프로그램이므로 기술적으로 완벽한 복제 방지는 아니다 — 원작자의 권리를 존중해 주세요.)
